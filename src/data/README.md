# Player archive

Imported on 24 October 2026 from Wikipedia player tables and the CC0 openfootball player archive. Coverage is broad, not exhaustive. Country lists include current and historical players; the Netherlands category requires senior international appearances. Club lists include historical official first-team appearances, with a curated Barcelona supplement for players below the main list's appearance threshold. Excluded reserve-only Ajax entries and Barcelona's Keirrison and Henrique (no official first-team appearances).

Scores are editorial estimates, not measured answer frequency. Archive-only names receive an estimated rarity of 0.2%; widely known added players have curated overrides in the question module.

## Positions and two-club questions

`club-position-data.json` is built from the Transfermarkt open dataset (https://github.com/dcaribou/transfermarkt-datasets, CC0: player positions, market values and transfer history) merged with Wikidata (CC0: positions and club membership, ordered by Wikipedia language editions), retrieved 25 October 2026. Each list is ordered by fame and the rarity estimate comes from the rank, so it is an editorial estimate like the rest. "Played for both X and Y" lists include players with a transfer touching both clubs, loans and youth moves included.
